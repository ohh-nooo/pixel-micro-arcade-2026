# NENORMOVA RETRO GAMER NASRAL 2026

Сборник микрогигр в духе WarioWare для браузера. Вертикальный экран, пиксельная графика, GBA-корпус. Главная особенность: **победить нельзя ни в одной игре**. Это часть дизайна, а не баг.

## Запуск

```bash
npm install
npm run dev
```

Открой адрес из терминала. Для сборки: `npm run build`, предпросмотр: `npm run preview`.

Проверка интерфейса: при запущенном `npm run dev` выполни `npm run check`. Скрипт обойдёт все микрогигры, проверит проигрыш, финал, рестарт и адаптив, а скриншоты сохранит во временную папку. Нужен установленный Chrome или Edge; другой браузер можно указать через `CHROME_PATH`.

## Управление

- `←` / `→` (или `A` / `D`) — влево / вправо.
- `Пробел` / `Enter` / клик по экрану — нажать / тап.
- На телефоне: тап по экрану, а на экранах с двумя кнопками — по большим кнопкам внизу.
- `M` — звук.

На ПК корпус зафиксирован по центру, без попыток растянуться на весь экран. Справа показана легенда. На телефоне интерфейс подстраивается под ширину экрана.

## Игры

1. **Гонка** — все полосы заняты, обгон невозможен.
2. **Прыжок** — прыжок всегда ниже препятствия.
3. **Тетрис** — падающая фигура не подходит к колодцу.
4. **Карта мира** — выбранный маршрут ведёт в никуда.
5. **Лабиринт** — оба ответвления заканчиваются тупиком.
6. **Слалом** — ряд деревьев перекрывает всю трассу.
7. **Крот** — в лунке бомба.
8. **Звездопад** — у корзины дырка.
9. **Пенальти** — вратарей оказывается трое.
10. **Башня** — ветер сдвигает блок, башня падает.

## Добавить новую игру

Создай файл в `src/games/`, например `src/games/clock.js`. Vite автоматически подхватит его через `import.meta.glob`, а `src/games/index.js` добавит в конец списка. Чтобы задать точный порядок, впиши `id` в `CONFIG.gameOrder` в `src/config.js`.

```js
import { C, fill, textCenter } from "../engine/gfx.js";

export default {
  id: "clock",
  title: "ЧАСЫ",
  hint: "Успей нажать до полуночи.",
  input: "tap", // "tap" | "sides"
  duration: 5,

  create(api) {
    let t = 0;

    return {
      update(dt) {
        t += dt;
        if (t > 2.5) api.lose("Стрелки сломались. Полночь наступила раньше.");
      },

      press(action) {
        // action.type: "left" | "right" | "tap"
        // у tap-игр есть action.x и action.y
        api.audio.pop();
      },

      draw(ctx) {
        fill(ctx, 0, 0, 240, 320, "#241d3d");
        textCenter(ctx, "12:00", 120, 140, { size: 36, color: C.paper });
      },
    };
  },
};
```

`api` содержит: `w`, `h`, `index`, `count`, `lose(message)`, `audio`, `rand`, `randInt`, `pick`, `clamp`. Экран всегда `240 × 320` и масштабируется CSS. Движок сам завершит игру по таймеру, но любая нормальная микрогигра должна сама вызвать `api.lose(...)` после короткой анимации.

## Заменить ассеты

Есть два способа.

### 1. PNG поверх встроенных спрайтов

Положи картинки в `public/assets/sprites/` и опиши их в `public/assets/manifest.json`:

```json
{
  "sprites": {
    "car": "assets/sprites/car.png",
    "runner": { "src": "assets/sprites/runner.png", "width": 8, "height": 12 }
  }
}
```

Ключи соответствуют спрайтам из `src/art.js` (`car`, `runner`, `tree`, `mole`, `bomb`, `star`, `ship`, `basket`, `ball`, `keeper`, `skull` и т. д.). `width`/`height` — «пиксельный» размер, в который картинка будет вписана; если их не указать, берётся размер встроенного спрайта. Можно рисовать PNG в большом разрешении — на экране он всё равно будет чётким за счёт `image-rendering: pixelated`.

Цвета `paint` (перекраска машин, курток, лыжника) работают только для встроенных спрайтов. PNG-замена используется как есть.

### 2. Палитра и ASCII-спрайты

Все встроенные спрайты — ASCII-картинки в `src/art.js`. Поменяй цвета в `PALETTE`, а символ `x` — это отдельный «канал краски», который игра задаёт при отрисовке:

```js
drawSprite(ctx, "car", x, y, { scale: 2.5, paint: "#e8473f" });
```

Общую палитру можно переопределить и из манифеста:

```json
{
  "palette": {
    "x": "#00ffaa",
    "y": "#ffcc00"
  }
}
```

Манифест не обязателен: если файла нет или картинка не загрузилась, используются встроенные спрайты.
